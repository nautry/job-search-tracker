# Daily job check

1. Open **Daily Dashboard**, the first visible tab of the existing tracker. Check collection/sync timestamps and employer-source warnings. GitHub collects once daily; do not rerun collection during a normal application session.
2. Review today's applications and due follow-ups. The dashboard selects up to five verified, unapplied roles with plausible May 2027 timing. It may show fewer than three, or zero; the explanation identifies why. No weak jobs are added to meet a quota.
3. Open the employer link. Confirm actual mechanical duties, degree, experience, start date, city, and your work authorization/export/clearance eligibility. Automated screening is evidence, not proof that you qualify or that interviews are occurring.
4. Choose **Mechanical Design**, **Test/R&D**, or **Mechatronics**. These are suggested resume categories; the tracker does not create or tailor resumes.
5. Submit directly to the employer. Use **Record / defer** to open the authoritative Jobs row. Set status and application date in A:B, optional follow-up and notes in C:D. Updating these fields removes completed roles and refills today's list after the revised bound script is installed.
6. If postponing a role, optionally set **Jobs AI: Deferred until**. It returns the day after that date. Use the existing **Not Interested** status to dismiss permanently. No extra review-status bookkeeping is required.
7. Use **Priority Queue** for more work. Today rows reference the dashboard assignments; Backlog is the remaining queue. **Needs Review** and **Stretch** are not validated recommendations to apply immediately.

Aim for 1–3 suitable applications in a 30–60 minute session. Follow up on RTX's verbal offer: obtain the written offer and decision deadline. Preserve the existing recorded follow-up until you intentionally update it.

The Job search menu offers **Refresh dashboard / refill** (views only) and **Refresh jobs** (imports the existing feed). Only use GitHub's Run workflow after a missed/failed collection. Product/program flags have zero ranking adjustment. The soft 70–75% defense/dual-use target never pads the queue.
